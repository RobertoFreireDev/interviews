# Products Frontend Context

**Stack:** React 19 + Vite  
**Port:** http://localhost:5173  
**Root:** `products/`

## Run
```bash
cd products && npm run dev
```

## Key files
- `products/src/` — all source
- Entry: `products/src/main.tsx`

## Rules
- Price stored/sent as cents (integer). Display only divides by 100.
- This app owns the `Product` entity only.
