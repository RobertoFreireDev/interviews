# Task 001 — Implement .NET 10 Web API for Products (Clean Architecture)

## Goal
Build a minimal .NET 10 C# Web API using clean architecture (Presentation, Application, Domain, Infra layers) that exposes a single GET Products endpoint backed by EF Core with SQL Server. All layers use GlobalUsings, async/await throughout, and the project ships with an xUnit unit test suite using NSubstitute for mocking.

## Scope
- Directory: `api/`
- Do not touch: `products/`, `inventory/`

## Acceptance criteria
- [ ] Solution has four projects: `Api` (Presentation), `Application`, `Domain`, `Infra`
- [ ] Each project has a `GlobalUsings.cs` file with its shared using directives
- [ ] `Api` uses minimal API controllers (no MVC controllers)
- [ ] `GET /Products/{searchterm}` endpoint is wired up and returns paginated results
- [ ] Connection string `DefaultConnection` targets `(localdb)\MSSQLLocalDB`, catalog `order`
- [ ] `GlobalExceptionHandler` is registered and handles unhandled exceptions
- [ ] All services/repositories are registered via an `IoC` extension method (`RegisterServices`)
- [ ] `Application` layer contains:
  - `Dtos/DataContracts/Request/` — request DTOs with `[Required]` annotations
  - `Dtos/DataContracts/Response/` — response DTOs
  - `Interfaces/` — `IProductService` and `IProductRepository`
  - `ProductService` (async)
  - `ProductMapper` (static class)
- [ ] `Domain` layer contains the `Product` domain class
- [ ] `Infra` layer contains:
  - `Entities/BaseEntity` (int Id) and `ProductEntity`
  - `ProductInventoryDbContext` with EF Core SQL Server provider
  - `ProductRepository` with `OnModelCreating` configuring `ValueGeneratedOnAdd` for Id
- [ ] Unit tests (xUnit + NSubstitute) cover `ProductService` — at minimum the happy path and a not-found/empty result case
- [ ] No external libraries other than EF Core (SQL Server provider) and NSubstitute
- [ ] Project builds without errors (`dotnet build`)

## Out of scope
- Authentication / authorization
- POST, PUT, DELETE endpoints
- Inventory endpoints
- Frontend integration
- Docker / deployment config
