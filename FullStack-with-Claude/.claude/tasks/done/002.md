# Task 002 — Bugfixes and adjustments: using statements, infra layer, and Swagger

## Context
Read `.claude/context/api.md` before starting (if present).

## Goal
Clean up the .NET Web API codebase by removing redundant `using` statements from all files except `GlobalUsings`, moving all infrastructure concerns (AddDbContext, EntityFrameworkCore references) into the Infra layer, and adding Swagger/SwaggerUI with automatic endpoint registration.

## Scope
- Directory: `api/`
- Do not touch: `products/`, `inventory/`

## Acceptance criteria
- [ ] No `using` statements exist in any class file except `GlobalUsings.cs`
- [ ] `AddDbContext` call is moved from the Presentation layer into the Infra layer
- [ ] `using Microsoft.EntityFrameworkCore;` is removed from the Presentation layer
- [ ] `Microsoft.EntityFrameworkCore` package reference exists only in the Infra project, not in Presentation
- [ ] Swagger and SwaggerUI are added (e.g. via `Swashbuckle.AspNetCore`) in the Infra layer
- [ ] All API endpoints are automatically registered and visible in Swagger UI at `/swagger`
- [ ] App builds and runs without errors after changes
- [ ] App run tests without errors after changes

## Out of scope
- Changes to frontend apps (`products/`, `inventory/`)
- Adding new API endpoints
- Database migrations
